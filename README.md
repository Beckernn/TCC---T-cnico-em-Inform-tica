# TCC---T-cnico-em-Inform-tica
Este é o meu trabalho de conclusão de curso do Curso Técnico em Informática integrado ao Ensino Médio. Este projeto aborda como principal tema a evasão escolar, e através da tecnologia unida a informação busca reduzir as taxas de evasão nas instituições de ensino superior do estado do Rio Grande do Sul.
